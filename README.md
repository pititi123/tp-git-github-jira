# Proyecto de Análisis de Ventas

# Descripción del Proyecto

Este proyecto fue desarrollado como trabajo práctico utilizando Python, Git, GitHub y Jira.

El objetivo principal es analizar información de ventas almacenada en un archivo CSV y generar estadísticas básicas junto con gráficos para visualizar los resultados.

Además, el proyecto aplica trabajo colaborativo utilizando versiones y gestión de tareas.



# Tecnologías Utilizadas

- Python
- Pandas
- Matplotlib
- Git
- GitHub
- Jira
